Publica la web de campaña del Decreto Mari Carmen en una dirección propia de tu web.

== Description ==

Muestra los 350 diputados del Congreso en un hemiciclo y permite escribirles para que voten a favor
de convalidar el Decreto Mari Carmen: a un grupo parlamentario entero (con todos en copia) o a cada
diputado desde su ficha. Incluye un contador común de correos preparados.

La web queda en https://tuweb/decretomaricarmen/ . No modifica tu tema, tus páginas ni tus ajustes.

== Installation ==

1. Plugins → Añadir nuevo plugin → Subir plugin → elige decreto-mari-carmen.zip → Instalar ahora.
2. Activa el plugin.
3. Ajustes → Decreto Mari Carmen: escribe el correo de contacto (y la organización, si firma alguien).

== Frequently Asked Questions ==

= ¿Dónde se configura? =
En Ajustes → Decreto Mari Carmen: correo de contacto, organización y dirección.

= ¿Cómo se retira? =
Desactiva el plugin. Si además lo borras, se eliminan sus ajustes.
